
create cron job

sudo crontab -e

# Example: Run a script every day at 3:30 AM
30 3 * * * /path/to/your/script.sh

The five fields represent 
(from left to right): minutes (0-59), hours (0-23), days of the month (1-31), months (1-12), 
and days of the week (0-6, where both 0 and 6 represent Sunday).

MIN HOUR DOM MON DOW CMD
(The first five fields, each separated by a single space, represent time intervals: 
MIN for minutes, HOUR for hours, DOM for day of the month, MON for month, and DOW for day of the week. 
They tell Cron when to initiate the cron job.)

for list
sudo crontab -l

check log

sudo cat /var/log/cron

for status

sudo systemctl status cron

for delete 

sudo crontab -r

sudo crontab -r -u username

-----------------------------------------------------
minute hour day month day_of_week command_to_run

minute: The minute when the job should run (0 - 59).
hour: The hour when the job should run (0 - 23).
day: The day of the month when the job should run (1 - 31).
month: The month when the job should run (1 - 12).
day_of_week: The day of the week when the job should run (0 - 6, where Sunday is 0 or 7).
command_to_run: The command or script to be executed.
-------------------------------------------------------
