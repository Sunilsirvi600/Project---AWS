
**** connect multiple instance with one efs ****

create 2 instances
security group
nfs = ipv4 everywhere
ssh = my ipv4

-------------------------------
now create efs file system

click on custormize
1) name of efs
2) class standard
3) Automatic backups ( enables )
4) click on next
5) select vpc where ur instance create
6) u also create policy
7) then next
8) Review and create 

now click on efs and attach
and copy using mount efs
*** sudo mount -t efs -o tls fs-01f3009c74cfa8954:/ efs ***   ( u also change last efs as per ur directory name )
